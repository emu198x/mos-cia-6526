# mos-cia-6526

The MOS 6526 complex interface adapter.

| Crate | Registry |
|---|---|
| [`emu198x-mos-cia-6526`](crates/emu198x-mos-cia-6526) | [crates.io](https://crates.io/crates/emu198x-mos-cia-6526) |

Part of [Emu198x](https://github.com/emu198x/emu198x), a family of
cycle-accurate retro-computing emulators. Used by the Commodore 64 and 128 and the 1571 and 1581 drives.

Each crate is versioned on its own and bumps only when it changes. Releases go
through release-plz: merging its release pull request tags the crate and
publishes it.
